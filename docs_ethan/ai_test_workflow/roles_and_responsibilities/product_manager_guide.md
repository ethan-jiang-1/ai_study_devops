# 产品经理角色指导：AI测试资产REVIEW

## 角色定位

您是AI测试资产生产流程中的**业务守护者**，负责确保AI生成的测试思路完整覆盖业务需求，符合用户期望和业务逻辑。

## 核心职责

### 1. 驱动阶段（业务需求澄清）
- **需求完整性确认**：确保业务需求描述完整准确
- **用户场景补充**：补充用户使用场景和用户体验要求
- **业务规则澄清**：明确复杂的业务规则和约束条件
- **优先级设定**：帮助确定测试场景的优先级

### 2. REVIEW阶段（您的主战场）
- **业务逻辑审核**：验证测试思路是否覆盖所有业务逻辑
- **场景完整性评估**：检查是否遗漏重要的业务场景
- **用户体验验证**：确保测试符合用户使用习惯
- **业务风险识别**：识别潜在的业务风险和问题

### 3. 反馈阶段（业务改进建议）
- **业务反馈整理**：整理和分类业务相关的反馈
- **改进建议提供**：提供具体的业务改进建议
- **验收标准设定**：设定业务验收标准

## 关键技能要求

### 必备技能
- **业务理解能力**：深度理解产品业务逻辑和用户需求
- **系统性思维**：具备全局思维和系统性分析能力
- **沟通协调能力**：能与技术团队和业务团队有效沟通
- **风险识别能力**：能够识别业务风险和潜在问题

### 进阶技能
- **测试理念理解**：理解测试的基本理念和方法
- **技术基础知识**：具备基本的技术理解能力
- **数据分析能力**：能够分析业务数据和用户行为

## 常见问题和解决方案

### 问题1：不知道如何评估技术实现的合理性
**解决方案**：
- 重点关注业务逻辑，技术实现由程序员负责
- 从用户角度思考功能是否符合预期
- 遇到技术问题时主动向程序员求助

### 问题2：测试思路过于技术化，难以理解
**解决方案**：
- 要求程序员提供业务语言的解释
- 关注测试的业务目的而非技术细节
- 使用业务场景对照检查

### 问题3：不确定某些边界条件是否重要
**解决方案**：
- 从业务风险角度评估影响
- 考虑用户实际使用场景
- 与业务专家讨论确认
