# 基础CRUD API测试指令模板

## 使用说明

本模板适用于基础的CRUD（增删改查）操作API测试用例生成。

**适用场景**：
- 用户管理API
- 商品管理API
- 分类管理API
- 配置管理API
- 其他简单的数据管理API

**使用方法**：
1. 复制下面的模板
2. 替换`{}`中的占位符
3. 根据具体业务补充详细信息
4. 发送给AI生成测试用例
