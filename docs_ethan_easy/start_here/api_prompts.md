## 💡 提示词使用技巧

### ✅ 这样写更好
- 具体描述业务场景，而不是泛泛而谈
- 提供真实的数据示例，比如"用户名3-20位字母数字"
- 说明业务重要程度，帮助AI判断测试深度
- 描述用户角色，帮助AI设计权限测试

### ❌ 避免这样
- 描述过于简单："测试用户API"
- 缺少业务规则：只说技术实现
- 忘记提供示例数据
- 没有说明重要程度

### 🎯 高质量示例
**好的描述**：
> 用户注册API，用于电商平台新用户注册。用户名3-20位字母数字组合且全局唯一，邮箱必须有效且唯一，密码8-50位包含字母数字特殊字符。注册成功后自动发送验证邮件。

**差的描述**：
> 用户注册接口，POST方法。
