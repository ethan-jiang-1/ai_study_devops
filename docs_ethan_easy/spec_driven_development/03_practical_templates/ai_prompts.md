# AI协作提示词模板

## 📋 使用说明

### 模板特点
- **结构化提示**：每个提示词都有清晰的结构
- **角色化设计**：针对不同角色的协作需求
- **质量控制**：内置质量检查和改进机制
- **可定制化**：可根据具体项目调整

### 使用方法
1. **选择合适的模板**：根据工作场景选择对应的提示词模板
2. **填写具体信息**：将模板中的变量替换为具体内容
3. **发送给AI**：将完整的提示词发送给AI
4. **检查AI输出**：使用质量检查清单验证AI输出
5. **迭代优化**：根据结果调整和优化提示词

### 适用场景
- 需求分析和整理
- 技术方案设计
- 测试用例生成
- 文档编写和优化
- 代码审查和改进
