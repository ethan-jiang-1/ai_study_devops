# CLAUDE.md - docs_ethan_easy 完整文档系统

## 📋 系统概览

docs_ethan_easy 是一个**完整的AI+测试+规范化开发文档系统**，包含76个文档文件，涵盖从快速入门到高级实践的完整学习路径。系统设计遵循"通俗易懂、循序渐进"的原则，适合产品经理、项目经理、测试工程师、开发工程师、管理者等不同角色使用。

## 🎯 系统定位和价值

### 核心理念
- **AI驾驭而非替代**：教会用户如何让AI成为得力助手
- **规范化而非束缚**：通过规范释放创造力，专注高价值工作
- **协作而非孤立**：跨职能团队高效协作的完整解决方案
- **实践而非理论**：每个概念都有具体的应用场景和模板
