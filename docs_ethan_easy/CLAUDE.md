# CLAUDE.md - AI测试工作流易用版文档系统

## 📋 项目概览

docs_ethan_easy 是一个**即用型AI测试工作流文档系统**，专为快速上手和实际应用设计。包含38个文档文件，13,370行内容，提供从基础模板到高级场景的完整测试生成解决方案。

## 🎯 系统定位

### 核心理念
- **先能用，再学深**：复制粘贴立即可用 → 看示例学习 → 深度定制
- **跨职能协作**：程序员驱动 + 非技术评审 + 迭代改进
- **快速迭代**：生成 → 评审 → 调整 → 重复

### 与 docs_ethan 的关系
- **docs_ethan**：理论框架和流程设计（协作流程）
- **docs_ethan_easy**：实践工具和模板库（立即可用）
- **互补定位**：理论指导 + 实践工具 = 完整体系
