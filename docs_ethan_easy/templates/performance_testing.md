# 性能压力测试模板

## 🎯 使用场景

当你的系统面临高并发、大数据量或严格的性能要求时使用此模板：
- 电商大促、秒杀活动
- 高并发访问场景
- 大数据处理系统
- 关键业务系统性能验证

## 💡 核心思路
这个高级提示词专注性能极限：**真实负载 + 全面监控 + 瓶颈识别**
- 详细描述系统架构（让AI理解性能瓶颈点）
- 明确性能目标（响应时间、吞吐量、资源使用）
- 强调监控分析（全链路监控、根因分析）
