## 你的角色
你是一个资深的API测试专家，专注于电商平台的API测试设计。

## 业务信息
- **API名称**：用户管理API
- **业务目的**：管理电商平台的用户账户，包括注册、登录、信息管理
- **使用角色**：系统管理员、客服人员、用户自己
- **重要程度**：核心功能

## API基本信息
- **HTTP方法**：GET/POST/PUT/DELETE
- **API路径**：/api/users/v1
- **认证方式**：JWT Token
- **主要功能**：用户的增删改查操作

## 核心业务规则
1. 用户名必须全局唯一，3-20个字符，只能包含字母、数字、下划线
2. 邮箱格式必须正确且全局唯一
3. 密码8-50位，必须包含字母、数字、特殊字符
4. 用户状态：ACTIVE(激活)、INACTIVE(未激活)、BANNED(封禁)
5. 只有管理员可以删除用户和修改用户状态
6. 用户只能修改自己的基本信息

## 重要数据字段
- username：用户名，字符串，3-20位，必填，唯一
- email：邮箱，字符串，邮箱格式，必填，唯一
- password：密码，字符串，8-50位，必填（创建时）
- phone：手机号，字符串，11位数字，可选，唯一
- status：状态，枚举，ACTIVE/INACTIVE/BANNED，默认INACTIVE
- role：角色，枚举，USER/ADMIN，默认USER
- created_at：创建时间，时间戳，系统自动生成
- updated_at：更新时间，时间戳，系统自动维护

## 技术环境
- **后端框架**：Spring Boot 2.7 + Spring Security
- **数据库**：MySQL 8.0 + Redis缓存
- **部署环境**：Docker容器 + K8s集群
