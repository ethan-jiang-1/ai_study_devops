# 业务逻辑检查清单

## 使用说明

本检查清单专为**产品经理**和**业务专家**设计，帮助您系统化地评估AI生成的测试思路是否完整覆盖业务逻辑。

**使用方法**：
1. 逐项检查每个要点
2. 在发现问题时记录具体问题
3. 给出改进建议
4. 标记优先级（高/中/低）

## 使用技巧

### 高效检查技巧
1. **重点关注**：优先检查核心业务流程和关键业务规则
2. **系统思考**：从业务价值角度思考测试的必要性
3. **用户视角**：站在用户角度思考业务逻辑的合理性
4. **风险导向**：重点关注高风险业务场景

### 常见问题识别
1. **业务规则遗漏**：检查是否所有业务规则都有对应测试
2. **异常处理不足**：检查异常情况的处理是否充分
3. **权限控制缺失**：检查权限验证是否完整
4. **状态管理混乱**：检查状态流转是否清晰

### 有效沟通建议
1. **具体描述**：问题描述要具体，避免模糊表述
2. **业务语言**：使用业务术语，避免技术术语
3. **建设性反馈**：不仅指出问题，还要提供改进建议
4. **优先级明确**：明确标识问题的优先级

---

**记住**：业务逻辑检查的目的是确保测试思路能够有效保障业务价值的实现。重点关注业务完整性、准确性和用户体验。
