# 需求文档模板

## 📋 使用说明

### 模板特点
- **填空式设计**：只需要填写具体信息，不用考虑格式
- **结构化描述**：使用EARS格式，确保需求清晰
- **检查清单**：内置质量检查，避免遗漏
- **示例说明**：每个部分都有示例参考

### 使用方法
1. **复制模板**：复制下面的模板内容
2. **创建文档**：在项目中创建需求文档
3. **填写信息**：根据提示填写具体内容
4. **质量检查**：使用内置检查清单验证
5. **团队评审**：组织团队评审确认

### 适用场景
- 新项目的需求收集
- 功能模块的需求描述
- 需求变更的文档化
- 跨团队的需求沟通

## 📝 使用提示

### 填写建议
1. **先整体后局部**：先填写项目基本信息，再填写具体需求
2. **多方参与**：邀请相关人员一起填写和评审
3. **重视验收标准**：每个需求都要有明确的验收标准
4. **保持更新**：需求变更时及时更新文档

### 常见问题
1. **需求太抽象**：使用EARS格式，增加具体的场景描述
2. **需求太复杂**：将复杂需求分解成多个简单需求
3. **需求不完整**：使用检查清单确保所有内容都有覆盖
4. **需求不一致**：定期评审，确保需求间的一致性

### 提高效率
1. **使用模板**：严格按照模板填写，不要跳过任何部分
2. **边写边评**：边写边和团队成员讨论，及时发现问题
3. **工具辅助**：使用项目管理工具管理需求
4. **经验积累**：每个项目结束后总结经验，改进模板

---

**记住**：好的需求文档是项目成功的基础。花时间把需求写清楚，后面的工作会事半功倍。这个模板帮助你规范化需求描述，确保不遗漏重要信息。
