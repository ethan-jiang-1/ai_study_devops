# 任务执行阶段 - 照猫画虎指南

## 🎯 本阶段目标

**执行测试计划** - 实际进行测试执行和结果验证

本阶段是四阶段流程的最终环节，基于前面三个阶段的成果，**实际执行测试计划并验证功能质量**。

**时间预期**：8-12分钟完成模板填写和执行指导

## 🎪 阶段核心价值

### 为什么任务执行如此重要？
```
计划完美 → 执行混乱 → 测试无效 → 质量失控 → 项目失败
计划完美 → 执行有序 → 测试有效 → 质量可控 → 项目成功
```

### 本阶段如何完成测试验证？
- **执行测试计划**：按照测试计划逐步执行所有测试任务
- **记录执行过程**：详细记录测试执行的过程和结果
- **验证质量标准**：确认功能满足所有需求和设计要求
- **处理发现问题**：及时处理和跟踪测试中发现的问题

## 🧭 执行思维导向

### 非技术化执行原则 ⭐
**重要**：本阶段避免直接展示代码，而是：
- 用**执行日志**记录实施和测试过程
- 用**AI指令**描述技术实现需求
- 用**测试结果**验证功能正确性
- 用**问题清单**跟踪和解决发现的问题

### 跨角色协作重点
- **产品经理**：参与验收测试，确认功能满足业务需求
- **开发人员**：实现功能并修复测试发现的问题
- **测试人员**：执行测试计划，验证功能质量
- **运维人员**：支持环境配置和部署准备

## 🚀 快速使用流程

### 第一次使用（推荐步骤）
1. **Review实施计划**：确保清楚理解要做的所有任务
2. **打开执行模板**：[execution_template_fill.md](./execution_template_fill.md)
3. **按计划执行任务**：逐个完成实施计划中的任务
4. **AI辅助实现**：使用[ai_assisted_coding.md](./ai_assisted_coding.md)协助功能实现
5. **执行测试验证**：使用[test_execution_copycat.md](./test_execution_copycat.md)执行测试
6. **记录和总结**：完整记录执行过程和最终结果

### 🤖 AI协作重点

#### 这个阶段如何使用AI？
- **功能实现**：使用AI协助生成实现方案和指导
- **测试执行**：使用AI协助测试用例执行和结果分析
- **问题诊断**：使用AI协助分析和解决遇到的问题
- **质量验证**：使用AI协助验证功能质量和完整性

#### AI协作原则
- **指导而非替代**：AI提供指导和建议，人做最终决策和验证
- **过程记录**：详细记录AI协作过程和决策依据
- **质量优先**：所有AI生成的内容都要经过人工验证
- **持续学习**：总结AI协作经验，持续改进协作方式

## 🚨 新手常见错误

### ❌ 错误做法
1. **跳过测试环节**：认为功能能运行就算完成，不执行完整测试
2. **忽略问题记录**：遇到问题解决了就算了，不记录和总结
3. **质量标准降低**：遇到困难就降低质量要求
4. **缺少验收确认**：没有正式的验收确认过程
5. **交付物不完整**：只关注功能实现，忽略文档和部署准备

### ✅ 正确做法
1. **严格执行测试**：按照测试计划完整执行所有测试环节
2. **详细记录过程**：记录所有执行过程、问题和解决方案
3. **坚持质量标准**：遇到困难寻求帮助，不降低质量要求
4. **正式验收确认**：与相关方进行正式的验收确认
5. **完整交付准备**：准备完整的交付物和部署文档

## 🌟 执行核心要点

### 从质量角度看执行
每个执行步骤都要问：
- **质量检查**：这一步的质量如何验证？
- **问题预防**：如何避免常见的执行问题？
- **结果确认**：如何确认这一步真正完成了？
- **风险控制**：如果出现问题如何快速恢复？

### 跨角色协作视角
任务执行要让每个角色都能：
- **产品经理**：了解实施进度，参与关键验收节点
- **开发人员**：清楚自己的任务和质量标准
- **测试人员**：按计划执行测试，及时反馈问题
- **运维人员**：准备部署环境，支持上线准备
