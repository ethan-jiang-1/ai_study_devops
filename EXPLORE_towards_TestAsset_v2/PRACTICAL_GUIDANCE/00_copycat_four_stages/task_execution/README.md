# 任务执行阶段 - 照猫画虎指南

## 🔥 TL;DR - 立即开始
> **目标**：执行测试计划 - 12分钟内完成核心执行记录
> 
> **行动**：打开[执行模板](./execution_template.md) → 填写6个[]空白 → 完成四阶段循环

## 🎯 阶段目标和价值

**核心目标**：执行测试计划 - 实际进行测试执行和结果验证

**为什么重要**：
```
计划完美 → 执行混乱 → 测试无效 → 质量失控 → 项目失败
计划完美 → 执行有序 → 测试有效 → 质量可控 → 项目成功
```

**时间预期**：12分钟

## ⚡ 12分钟快速流程

### 🎯 快速使用步骤
```
步骤1：回顾计划 → 确认上一阶段的实施规划
步骤2：打开模板 → execution_template.md
步骤3：边执行边记录 → 6个[]空白，实时填写
步骤4：快速检查 → 确认执行完整
步骤5：庆祝完成 → 你已完成第一个四阶段循环！
```

### 🤖 AI协作要点
- **实现时用AI**：不知道怎么实现就用AI协助
- **测试时用AI**：不知道怎么测试就用AI指导
- **问题时用AI**：遇到bug就用AI帮助诊断

## 🚨 避免这些错误
1. ❌ **跳过测试环节**：功能能运行就算完成 → ✅ **严格测试**：按计划执行所有测试
2. ❌ **忽略问题记录**：解决了就忘记 → ✅ **详细记录**：记录问题和解决过程
3. ❌ **质量标准降低**：遇到困难就妥协 → ✅ **坚持标准**：寻求帮助，不降低质量
4. ❌ **缺少交付物**：只关注功能实现 → ✅ **完整交付**：包含文档和部署准备

## 🆘 遇到问题？

### 🔍 常见问题快速解决
- **不知道怎么实现**：用AI问 `[功能名]应该怎么实现？请提供指导思路`
- **不知道怎么测试**：用AI问 `[功能名]应该怎么测试验证？`
- **遇到Bug**：用AI问 `这个问题可能是什么原因？如何解决？`
- **时间不够**：先完成核心功能，后续再完善
