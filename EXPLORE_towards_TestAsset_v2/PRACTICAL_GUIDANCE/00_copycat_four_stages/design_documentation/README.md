# 设计文档阶段 - 照猫画虎指南

## 🔥 TL;DR - 立即开始
> **目标**：明确"怎么测" - 8分钟内完成设计方案
> 
> **行动**：打开[设计模板](./design_template.md) → 填写7个[]空白 → 前往规划阶段

## 🎯 阶段目标和价值

**核心目标**：明确"怎么测" - 制定测试策略和测试方法

**为什么重要**：
```
需求明确 → 设计混乱 → 实现困难 → 测试盲目 → 质量无保障
需求明确 → 设计清晰 → 实现顺畅 → 测试有序 → 质量可控
```

**时间预期**：8分钟

## ⚡ 8分钟快速流程

### 🎯 快速使用步骤
```
步骤1：回顾需求 → 确认上一阶段的需求澄清结果
步骤2：打开模板 → design_template.md
步骤3：填写内容 → 7个[]空白，每个1分钟
步骤4：快速检查 → 确认设计逻辑清晰
步骤5：进入下一阶段 → 点击模板底部链接
```

### 🤖 AI协作要点
- **卡住了就问AI**：超过1分钟不知道怎么填就用AI
- **万能提示词**：`[功能名]一般采用什么实现方案和测试策略？`
- **人工决策**：AI提供选项，人选择最适合的

## ✅ 完成标准
- [ ] 7个[]都已填写
- [ ] 明确了实现的核心逻辑和关键组件
- [ ] 知道如何测试这个设计
- [ ] 考虑了安全和性能要求
- [ ] 在8分钟内完成

## 🚨 避免这些错误
1. ❌ **设计太技术化**：写代码细节 → ✅ **业务化表达**：用自然语言描述逻辑
2. ❌ **忽略测试设计**：只考虑实现 → ✅ **测试优先**：每个设计都考虑如何测试
3. ❌ **过度设计**：想得太复杂 → ✅ **够用即可**：简单可行就够了
4. ❌ **跳过安全考虑**：只考虑功能 → ✅ **安全必备**：每个功能都要考虑安全

## 🆘 遇到问题？

### 🔍 常见问题快速解决
- **不知道怎么实现**：用AI问 `[功能名]一般用什么方案实现？`
- **不知道怎么测试**：用AI问 `[功能名]应该怎么测试验证？`
- **时间超过8分钟**：简化设计，先实现核心功能
- **设计太复杂**：问自己"最简单的方案是什么？"

### 🤖 万能AI求助
```
我正在做[具体项目]的设计文档，在第[X]个空白遇到困难。

需求概述：[简单描述需求]
我的困惑：[具体困难]

请帮我：这个设计点应该考虑什么？有什么简单可行的方案？
```
