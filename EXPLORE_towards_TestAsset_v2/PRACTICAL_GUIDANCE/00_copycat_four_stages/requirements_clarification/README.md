# 需求澄清阶段 - 照猫画虎指南

## 🔥 TL;DR - 立即开始
> **目标**：明确"测什么" - 5分钟内完成需求澄清
> 
> **行动**：打开[需求模板](./requirements_template.md) → 填写6个[]空白 → 前往设计阶段

## 🎯 阶段目标和价值

**核心目标**：明确"测什么" - 确定测试范围和验收标准

**为什么重要**：
```
需求不清 → 设计偏差 → 实现错误 → 测试无效 → 返工重做
需求明确 → 设计准确 → 实现正确 → 测试有效 → 一次成功
```

**时间预期**：5分钟（超简版）或15分钟（完整版）

## ⚡ 5分钟快速流程

### 🎯 第一次使用（严格按此步骤）
```
步骤1：确认项目 → 选择"用户登录API"
步骤2：打开模板 → requirements_template.md
步骤3：填写内容 → 6个[]空白，每个30秒
步骤4：快速检查 → 确认所有[]都已填写
步骤5：进入下一阶段 → 点击模板底部链接
```

### 🤖 AI协作要点
- **卡住了就问AI**：超过30秒不知道怎么填就用AI
- **万能提示词**：`我在做[项目名]的需求澄清，这个[]应该填什么内容？`
- **人工决策**：AI提供建议，人做最终决定

---

## ✅ 完成标准（超简版）
- [ ] 6个[]都已填写
- [ ] 能用一句话说明功能是做什么的
- [ ] 知道如何判断功能是否正确工作
- [ ] 在5分钟内完成

## 🚨 避免这些错误
1. ❌ **填写太抽象**："系统要好用" → ✅ **具体化**："登录响应时间<2秒"
2. ❌ **跳过空白**：觉得某个[]不重要 → ✅ **全部填写**：每个[]都有价值
3. ❌ **过度思考**：花10分钟思考一个空白 → ✅ **快速填写**：不确定就用AI
4. ❌ **完美主义**：要写出完美需求 → ✅ **够用即可**：照猫画虎就行

---

## 🆘 遇到问题？

### 🔍 常见问题快速解决
- **不知道填什么**：用AI问 `[项目名]的用户一般有什么需求？`
- **感觉太简单**：第一次就用超简版，后续再用完整版
- **时间超过5分钟**：选择更简单的项目（如"两数相加API"）
- **不确定对错**：先填完，在下个阶段验证

### 🤖 万能AI求助
```
我正在做[具体项目]的需求澄清，在第[X]个空白遇到困难。

这个功能是：[简单描述]
我的困难是：[具体困难]

请帮我：填写这个空白应该写什么内容？
```
