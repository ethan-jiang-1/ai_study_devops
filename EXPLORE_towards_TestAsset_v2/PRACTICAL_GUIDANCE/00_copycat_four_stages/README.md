## 🎪 核心理念：先会做，再理解

### 什么是"照猫画虎"？
- **完全模仿**：不要创新，严格按模板填空
- **填空练习**：看到[]就填写，不要跳过
- **测试导向**：每个阶段都问"这如何帮助我测试？"
- **AI协助**：卡住了就用AI，但人要做最终决策

### 四阶段如何服务测试？
```
需求澄清 → 明确"测什么"（测试范围和验收标准）
设计文档 → 明确"怎么测"（测试策略和方法）
实施规划 → 明确"测试步骤和资源"（测试序列和环境）
任务执行 → 执行测试计划（测试执行和结果验证）
```

## 🚨 新手必读：避免这些错误

### ❌ 常见错误（会导致失败）
1. **跳过阶段**：想直接编码 → 必须按顺序完成四阶段
2. **过度创新**：不按模板执行 → 严格填空，不要自由发挥
3. **忽略测试**：只关注实现 → 每步都问"如何测试？"
4. **AI依赖**：让AI代替思考 → AI辅助，人做决策

### ✅ 成功做法
1. **严格按序**：requirements → design → implementation → execution
2. **模板优先**：看到[]就填写，完全按模板来
3. **测试导向**：每个步骤都思考如何服务于测试
4. **时间控制**：每个阶段不超过预估时间，有问题立即求助
