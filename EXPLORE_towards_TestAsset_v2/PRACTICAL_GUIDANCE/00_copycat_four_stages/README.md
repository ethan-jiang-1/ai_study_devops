# 照猫画虎：四阶段模仿实践

## 🎯 阶段目标

**30分钟内完成第一个完整的四阶段循环**，通过直接模仿掌握基础操作，不要求深度理解。

本阶段的核心理念是：**先会做，再理解**。我们提供完整的模板和填空式指导，让你能够立即上手，在实践中逐步理解方法论的价值。

## 📋 学习成果预期

完成本阶段学习后，你将能够：
- ✅ 使用模板完成需求澄清，明确"测什么"
- ✅ 使用模板完成设计文档，明确"怎么测"  
- ✅ 使用模板完成实施规划，明确"测试步骤和资源"
- ✅ 使用模板完成任务执行，进行"测试计划执行"
- ✅ 掌握基础AI协作技巧（搜索、填空、检查）
- ✅ 理解四阶段如何服务于最终的测试计划

## 🏗️ 四阶段模仿路径

### 📝 [requirements_clarification](./requirements_clarification/) - 需求澄清模仿
**目标**：明确"测什么" - 确定测试范围和验收标准  
**时间**：5-8分钟  
**产出**：需求文档 + 验收标准 + 测试范围  
**AI工具**：需求信息搜索 + 需求完整性检查

### 🎨 [design_documentation](./design_documentation/) - 设计文档模仿  
**目标**：明确"怎么测" - 设计测试策略和方法  
**时间**：8-10分钟  
**产出**：设计文档 + 测试策略 + 测试方法  
**AI工具**：解决方案研究 + 设计质量评估

### 📊 [implementation_planning](./implementation_planning/) - 实施规划模仿
**目标**：明确"测试步骤和资源" - 规划测试序列和环境  
**时间**：8-10分钟  
**产出**：实施计划 + 测试计划 + 资源清单  
**AI工具**：任务分解 + 风险评估

### ⚡ [task_execution](./task_execution/) - 任务执行模仿
**目标**：执行测试计划 - 实际进行测试执行和结果验证  
**时间**：8-12分钟  
**产出**：执行日志 + 测试结果 + 质量报告  
**AI工具**：代码生成 + 测试执行 + 结果分析

## 🚀 快速开始指南

### 第一次使用（推荐流程）
1. **选择练习项目**：从简单的API功能开始（如用户登录、数据查询）
2. **按顺序完成四阶段**：requirements → design → implementation → execution
3. **严格使用模板**：不要创新，完全按照模板填空
4. **关注测试导向**：每个阶段都思考如何服务于最终测试
5. **记录问题和感受**：为后续学习做准备

### 练习项目建议

#### 🌟 超简单项目（首次练习）
- **用户登录API**：用户名密码验证
- **数据查询接口**：根据ID查询用户信息
- **简单计算功能**：两数相加的API

#### ⭐ 简单项目（第2-3次练习）
- **用户注册功能**：包含数据验证和存储
- **文件上传接口**：支持图片上传和格式检查
- **简单CRUD操作**：创建、读取、更新、删除

#### 🌟 稍复杂项目（第4-5次练习）
- **购物车功能**：添加商品、计算总价
- **评论系统**：发表评论、点赞、回复
- **简单工作流**：申请-审批-通知

## 🤖 AI协作入门

### 本阶段AI能力重点
- **AI + Search**：搜索相关需求和技术信息
- **AI + 填空**：根据模板生成具体内容
- **AI + 检查**：验证完成质量和完整性

### AI工具使用技巧
1. **具体明确**：给AI具体的上下文和要求
2. **分步进行**：不要一次要求AI完成所有内容
3. **人工审核**：AI生成的内容需要人工检查和调整
4. **迭代改进**：根据AI反馈不断完善prompt

## 🚨 新手常见问题

### ❌ 常见错误
1. **跳过阶段**：想直接进入编码，忽略前期规划
2. **过度创新**：不按模板执行，自己发挥创造
3. **忽略测试**：关注实现忽略验证方法
4. **AI依赖**：完全依赖AI，不进行人工思考

### ✅ 正确做法
1. **严格按序**：必须按 requirements → design → implementation → execution 顺序
2. **模板优先**：完全按照模板填空，不要自由发挥
3. **测试导向**：每个步骤都问"这如何帮助我测试"
4. **人机协作**：AI辅助人工决策，而非AI替代思考
