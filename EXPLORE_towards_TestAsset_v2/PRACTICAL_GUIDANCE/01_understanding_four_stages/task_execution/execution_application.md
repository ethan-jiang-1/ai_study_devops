## 🔍 3步法AI智能执行协作流程

### 第1步：任务分析与代码生成（3-4分钟）
**目标**：快速理解任务要求并生成初版代码

**简化提问模板**：
```
请帮我分析和实现任务[具体任务名称]：
1. 技术实现的核心要求是什么？
2. 请生成符合要求的代码实现
3. 代码需要注意哪些关键质量点？

请直接提供可用的代码实现。
```

**2轮对话示例**：
```
第1轮：用户：请分析电商用户登录功能并生成JWT认证代码
AI：[提供技术分析和代码实现]

第2轮：用户：这个实现的安全性如何？需要补充什么？
AI：[给出安全性评估和改进建议]
```

### 第2步：质量检查与问题解决（3-4分钟）
**目标**：深入检查代码质量并解决关键问题

**核心关注点**：
```
质量检查：
- "请检查代码的功能正确性和安全性"
- "是否处理了边界情况和异常情况？"

问题诊断：
- "代码可能存在什么技术风险？"
- "如何测试和验证这个实现？"（30%强度测试思维体现）
```

### 第3步：优化完善与交付准备（2-3分钟）
**目标**：优化代码并准备交付

**实施决策**：
```
代码优化：
- "还有哪些可以改进的地方？"
- "如何提高代码的可维护性？"

交付准备：
- "部署时需要注意什么？"
- "后续维护的关键点有哪些？"
```

## 💡 AI执行协作高级技巧

### 🔍 多场景执行对比技巧
```
场景对比提问：
"请对比以下3种实现方案的优劣：
1. 传统MVC架构实现
2. 微服务架构实现  
3. Serverless架构实现

从开发效率、运维成本、扩展性三个维度分析。"
```

### 🎯 代码质量评估技巧
```
质量评估提问：
"请从以下维度评估这段代码的质量：
1. 功能正确性：逻辑是否正确，边界处理是否完善
2. 代码可读性：命名、结构、注释是否清晰
3. 性能效率：是否存在性能瓶颈和优化机会
4. 安全性：是否存在安全漏洞和风险
5. 可维护性：是否易于理解、修改和扩展

并提出具体的改进建议。"
```

### 🚀 问题解决技巧
```
问题解决提问：
"我在执行中遇到[具体问题描述]，请帮我：
1. 分析问题的可能原因（至少3个维度）
2. 提供可行的解决方案（至少2个方案）
3. 评估每个方案的优劣和风险
4. 推荐最佳解决方案并说明理由
5. 提供验证解决方案有效性的方法"
```

## 🎯 项目适应性调整：类型驱动的执行策略

### 📊 2种典型项目的执行调整

#### 🚀 快速交付型项目（MVP、原型验证）
**项目特征**：
- 时间要求紧迫，快速验证为主
- 重点关注核心功能实现
- 技术债务可控积累

**执行重点调整**：
```
核心关注点：
✅ 快速实现核心功能，验证业务价值
✅ 简化实现方案，避免过度设计
✅ 快速迭代和用户反馈收集
✅ 技术债务的有意识管理

执行策略特色：
- 原型驱动：先做出可用的原型再优化
- 功能聚焦：只实现最核心的功能特性
- 快速验证：每个功能都要快速验证可行性
- 迭代优化：基于用户反馈快速迭代

AI协作重点调整：
- 代码生成：要求AI生成简单直接的实现方案
- 质量检查：重点检查功能正确性，合理控制质量标准
- 问题解决：优先选择快速可行的解决方案
```

#### 🏗️ 稳定质量型项目（企业系统、关键业务）
**项目特征**：
- 质量要求高，稳定性关键
- 长期维护和演进需求
- 多方面合规要求

**执行重点调整**：
```
核心关注点：
✅ 代码质量和系统稳定性保证
✅ 完善的错误处理和异常管理
✅ 全面的测试覆盖和验证
✅ 详细的文档和知识管理

执行策略特色：
- 质量优先：每个环节都有严格的质量标准
- 测试驱动：先设计测试再实现功能
- 文档完善：代码、设计、操作文档齐全
- 渐进上线：分阶段验证和部署

AI协作重点调整：
- 代码生成：要求AI生成企业级质量的代码
- 质量检查：全面检查代码质量、安全性、性能
- 问题解决：优先考虑长期稳定性的解决方案
```

## 🚨 避免实践应用陷阱

### 1️⃣ AI执行依赖陷阱
❌ **错误做法**：完全依赖AI的代码生成  
✅ **正确做法**：基于技术理解进行AI协作  

### 2️⃣ 质量检查形式化陷阱
❌ **错误做法**：认为跑了检查清单就是质量保证  
✅ **正确做法**：理解质量标准背后的原理和目的  

### 3️⃣ 执行过程黑盒陷阱
❌ **错误做法**：只关注最终结果，忽视执行过程  
✅ **正确做法**：在执行过程中持续验证和控制质量  

### 4️⃣ 完美主义执行陷阱
❌ **错误做法**：追求每个细节都完美  
✅ **正确做法**：根据项目特点平衡质量要求和执行效率
