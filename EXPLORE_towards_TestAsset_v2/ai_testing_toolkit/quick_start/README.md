# 立即开始 - 复制粘贴提示词

## 🎯 选择你的测试场景

### API测试 → [api_prompts.md](./api_prompts.md)
- **基础CRUD API**：用户管理、商品管理等
- **复杂业务API**：订单处理、支付流程等
- **系统集成API**：第三方API调用、数据同步等

### 界面测试 → [ui_prompts.md](./ui_prompts.md)
- **Web网页测试**：网站页面、后台管理系统
- **移动APP测试**：iOS、Android应用
- **桌面软件测试**：Windows、Mac应用

### 数据库测试 → [database_prompts.md](./database_prompts.md)
- **关系型数据库**：MySQL、PostgreSQL等
- **NoSQL数据库**：MongoDB、Redis等
- **缓存数据库**：Redis、Memcached等
- **数据仓库**：ClickHouse、Snowflake等

## 📋 使用步骤

1. **点击上面的链接** → 选择适合你的测试场景
2. **复制提示词模板** → 找到合适的模板复制
3. **替换占位符** → 把{}中的内容替换成你的信息
4. **发送给AI** → 粘贴到任何AI工具中
5. **获得测试方案** → AI会生成完整的测试用例

- 信息不全？先填写关键信息，后续可以补充
