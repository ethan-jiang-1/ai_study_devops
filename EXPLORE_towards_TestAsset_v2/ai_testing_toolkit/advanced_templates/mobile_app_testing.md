# 移动应用深度测试模板

## 🎯 使用场景

当你需要对移动应用进行深度测试，超越基础UI测试时使用此模板：
- 原生iOS/Android应用
- 混合应用（React Native、Flutter、Ionic）
- 复杂手势和交互操作
- 多设备兼容性验证
- 设备特性深度集成

## 💡 核心思路
这个高级提示词专注移动端复杂性：**设备特性 + 性能优化 + 用户体验**
- 充分利用设备硬件特性（摄像头、GPS、传感器）
- 重视移动端性能约束（电量、内存、网络）
- 强调真实使用场景（中断、后台、多任务）

## 🛠️ 模板填写指南

### 移动应用类型识别
- **原生应用**：Swift/Kotlin开发，性能最佳
- **混合应用**：React Native/Flutter，跨平台
- **Web应用**：PWA/响应式Web，兼容性好
- **小程序**：微信/支付宝小程序，生态集成

### 设备特性利用程度
- **基础使用**：基本UI交互，标准功能
- **中度集成**：摄像头/定位等硬件功能
- **深度集成**：传感器/生物识别/AR功能
- **系统级集成**：系统服务/后台处理/推送

### 性能要求分级
- **性能敏感**：游戏/视频/AR应用
- **标准性能**：社交/工具/电商应用
- **性能宽松**：阅读/新闻/简单工具

## 💡 高级使用技巧

### ✅ 提升测试质量
1. **真实设备测试**：使用真实设备而非模拟器
2. **多维度覆盖**：功能+性能+兼容性+用户体验
3. **场景化测试**：模拟真实用户使用场景
4. **自动化结合**：手工+自动化测试相结合

### ✅ 复杂场景处理
1. **分层测试策略**：单元→集成→系统→验收
2. **渐进式兼容**：核心设备→扩展设备→边缘设备
3. **性能基准**：建立性能基准和监控体系
4. **持续优化**：基于用户反馈持续优化

### ✅ 团队协作优化
1. **跨平台协作**：iOS/Android团队协作
2. **设计开发联动**：设计师/开发者/测试协作
3. **用户反馈闭环**：用户反馈→测试改进→体验提升
4. **知识共享**：移动端测试经验分享
