# 数据迁移测试模板

## 🎯 使用场景

当你需要进行大规模数据迁移，确保数据完整性和系统稳定性时使用此模板：
- 系统升级的数据迁移
- 数据库平台迁移
- 云平台数据迁移
- 数据中心迁移
- 数据格式转换迁移

## 💡 核心思路
这个高级提示词专注迁移复杂性：**数据完整性 + 迁移风险控制 + 性能优化**
- 详细描述数据特征（让AI理解数据规模、格式、依赖关系）
- 明确迁移策略（全量迁移、增量迁移、分批迁移）
- 强调风险管控（数据验证、回滚方案、影响评估）

## 🛠️ 模板填写指南

### 迁移类型分类
- **系统升级迁移**：数据库版本升级、应用系统升级
- **平台迁移**：不同数据库平台间迁移
- **云迁移**：本地到云端、云端间迁移
- **数据中心迁移**：物理位置的迁移

### 数据规模分级
- **小规模**：GB级数据，百万级记录
- **中规模**：TB级数据，千万级记录
- **大规模**：PB级数据，十亿级记录
- **超大规模**：EB级数据，万亿级记录

### 迁移工具选择
- **开源工具**：Kettle、Talend、DataX、Sqoop
- **商业工具**：Informatica、IBM DataStage、Oracle GoldenGate
- **云原生工具**：AWS DMS、Azure Database Migration Service
- **自研工具**：基于业务特点的自开发工具

## 💡 高级使用技巧

### ✅ 提升迁移质量
1. **分阶段验证**：迁移前中后的全程验证
2. **多维度检查**：完整性、一致性、准确性全面检查
3. **自动化验证**：建立自动化的数据验证流程
4. **实时监控**：迁移过程的实时监控和告警

### ✅ 复杂场景处理
1. **大数据量处理**：分批迁移、并行处理、性能优化
2. **复杂依赖处理**：依赖关系梳理、迁移顺序设计
3. **数据格式转换**：格式转换的准确性验证
4. **异构系统迁移**：不同系统间的数据映射

### ✅ 风险控制策略
1. **多重备份**：关键数据的多重备份保护
2. **渐进式迁移**：从小到大的渐进式迁移
3. **灰度发布**：部分数据的灰度迁移验证
4. **快速回滚**：完整的回滚方案和验证
